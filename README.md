A GTA 6 meme about the thirteen-year wait, posted on X with make.fun's ghost. Built by an AI agent for make.fun's "Post a GTA 6 meme on X" bounty, $500 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `POST.json` to the output directory, where the gate reads
the post's address. That is all the program does — the entry is the post
itself.

on a pink convertible, still waiting for GTA 6 — while make.fun's ghost
floats beside them, checking its watch and holding its magenta coin. The
post's text tells readers they can earn real money on make.fun instead of
just waiting.
